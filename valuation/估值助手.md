# 估值助手

浏览器里的估价对话。用户只输入一句话，本地 Ollama 模型决定调用「查询案例」「估值」或「出报告」。工具在 Python 里执行，结果画回对话，再交给模型写成中文结论。

循环方式和 `agent_wf.py` 相同。模型只负责选工具和填参数，不直接编造价格。

| 文件 | 作用 |
| --- | --- |
| `index.html` | 对话页面 |
| `agent_server.py` | 会话、Agent 循环、把页面和接口串起来 |
| `tools.py` | 三个工具。地址为空时用示例数据，填上地址后改为 POST 真实接口 |

`README.md` 写的是另一个浏览器示例（`add` / `multiply`），和本页不是同一套文件。

## 怎么跑

本机需要已经启动 Ollama，并已有模型 `qwen3.5:9b`。页面不直连 Ollama，所以不用设置 `OLLAMA_ORIGINS`。

```bash
cd /path/to/agentTest
.venv/bin/python agent_server.py
```

浏览器打开：

```text
http://127.0.0.1:8765
```

顶栏显示 `qwen3.5:9b 已连接` 就可以输入。模型未启动时显示「模型未连接」。

这台机器用 CPU 跑模型，一轮常常要一两分钟。请求进行时，发送按钮变成「停止」。

## 页面怎么用

左侧是会话列表，右侧是当前对话。底部只有一个输入框。三个胶囊按钮只把示例句子填进输入框，不会直接发送。

- Enter 发送，Shift+Enter 换行
- 输入为空时不能发送
- 一次只能处理一条请求

可以连着说。例如先查案例，下一句「根据刚才的结果做估值」，再下一句「出一份报告」。同一会话会保留历史，模型能用到上一轮的案例编号和估值编号。

模型调用工具时，对话里出现一张卡片，状态从「调用中」到「已完成」或「失败」。示例数据会写成「已完成，示例数据」。没有工具调用时，下一条是模型的最终回答。

会话只存在这次服务进程的内存里。重启 `agent_server.py` 后，历史对话会清空。

## 一轮请求里发生什么

```text
输入框
  │
  ▼
POST /api/chat          浏览器只跟 8765 说话
  │
  ▼
┌──────────────────┐
│ Ollama qwen3.5:9b │  messages + 三个工具
└────────┬─────────┘
         │
         ├─ 无 tool_calls ──► 最终回答，结束
         │
         └─ 有 tool_calls ──► tools.py 执行
                                │
                                ▼
                           结果写回 messages，进入下一轮
```

最多 10 轮。Ollama 返回 502 或 503 时，等 3 秒再试，最多 3 次。请求直连 `http://127.0.0.1:11434`，不走系统代理。

## 三个工具

模型看到的是函数名和参数说明。真正的 HTTP 调用在 `tools.py`。三个地址都留空时走示例数据：

```python
SEARCH_CASES_URL = ""
VALUATION_URL = ""
GENERATE_REPORT_URL = ""
```

填入地址后，对该地址 POST JSON，请求体就是下表里的参数。响应必须是 JSON 对象，字段与示例结果一致。`ok` 可以省略，省略时按成功处理。失败时返回 `{"ok": false, "error": "原因"}`。接口报错不会改回示例数据。

价格单位是元，面积单位是平方米。

### 查询案例 `search_cases`

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `keyword` | 是 | 小区名或地址，例如望京新城 |
| `district` | 否 | 行政区，例如朝阳区 |
| `area_min` | 否 | 最小建筑面积 |
| `area_max` | 否 | 最大建筑面积 |

成功时返回：

```json
{
  "ok": true,
  "summary": "找到 2 条成交案例",
  "cases": [
    {
      "id": "C2026-001",
      "community": "望京新城",
      "address": "朝阳区望京新城 3 号楼",
      "district": "朝阳区",
      "area": 89.2,
      "price": 6850000,
      "unit_price": 76794,
      "deal_date": "2026-08-12",
      "property_type": "住宅"
    }
  ]
}
```

没有命中时 `ok` 仍为 true，`cases` 为空。关键词和行政区都空着时 `ok` 为 false。

### 估值 `valuation`

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `address` | 是 | 地址或小区名 |
| `area` | 是 | 建筑面积 |
| `property_type` | 否 | 住宅、别墅、商办。不填按住宅 |
| `floor` | 否 | 例如高楼层、低楼层 |
| `case_ids` | 否 | 案例编号列表，也可以是逗号分隔的字符串 |

成功时返回：

```json
{
  "ok": true,
  "valuation_id": "V0001",
  "address": "朝阳区望京新城",
  "area": 89,
  "property_type": "住宅",
  "floor": "",
  "unit_price": 76968,
  "total_price": 6850152,
  "basis": "估价依据",
  "case_ids": ["C2026-001", "C2026-002"],
  "references": [
    {
      "id": "C2026-001",
      "address": "朝阳区望京新城 3 号楼",
      "unit_price": 76794,
      "deal_date": "2026-08-12"
    }
  ],
  "summary": "评估单价 76,968 元/平方米，总价 6,850,152 元"
}
```

页面用 `unit_price`、`total_price`、`basis`、`valuation_id` 和 `references` 画卡片。真实接口只要带上这些字段，卡片就能显示。

### 出报告 `generate_report`

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| `subject` | 是 | 评估对象，例如「朝阳区望京新城 89 平」 |
| `valuation_id` | 否 | 不填则用本进程里最近一次估值 |
| `case_ids` | 否 | 不填则用该次估值引用的案例 |

成功时返回：

```json
{
  "ok": true,
  "report_id": "R0001",
  "title": "朝阳区望京新城 89 平估价报告",
  "summary": "一句话摘要",
  "content": "报告全文",
  "valuation_id": "V0001",
  "case_ids": ["C2026-001"]
}
```

页面展示标题和摘要，全文放在「展开全文」里，并可以下载为文本文件。

示例数据下，报告会带上「当前内容来自本地示例接口」这类说明。换成真实接口后，正文就是接口返回的 `content`。

## 页面接口

浏览器只访问 `127.0.0.1:8765`。

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| GET | `/` | 返回 `index.html` |
| GET | `/api/health` | 模型名、Ollama 是否可连、是否仍在用示例数据 |
| GET | `/api/sessions` | 会话列表 |
| POST | `/api/sessions` | 新建会话 |
| GET | `/api/sessions/{id}` | 某个会话的对话记录 |
| POST | `/api/chat` | 发送一句需求，响应是 SSE |
| POST | `/api/chat/stop` | 停止当前这句 |

`POST /api/chat` 的请求体：

```json
{ "session_id": "会话 id", "message": "朝阳区望京新城 89 平，请估值" }
```

重试时不带新的用户句子：

```json
{ "session_id": "会话 id", "retry": true }
```

SSE 事件的 `type` 有：`session`、`status`、`tool_call`、`tool_result`、`assistant`、`error`、`stopped`、`done`。

## 请求失败时看什么

1. 顶栏是「模型未连接」：确认 Ollama 在 `127.0.0.1:11434`，并且已有 `qwen3.5:9b`。
2. 对话里出现 502 或 503：模型进程没把结果交回来。服务会自动重试。内存很紧时，重试也会失败，需要先减轻内存占用。
3. 卡片是「失败」：看卡片里的错误文本。多半是参数不完整，或真实接口返回了错误。
4. 价格看起来像演示数据：`tools.py` 里对应的 URL 还是空的。三个都填上并重启服务后，顶栏下方的说明不再提示示例数据。
